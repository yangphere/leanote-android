# Leanote API 与内容兼容实施计划

## 契约盘点

- [ ] 清点 `network/api` 全部目标服务调用，记录 HTTP 方法、路径、参数、DTO、错误和认证要求。
- [ ] 从现有服务层提取 USN 分页、删除、上传、冲突副本、Markdown/HTML 和附件身份不变量。
- [ ] 建立脱敏的请求/响应/错误夹具，禁止把真实凭据、令牌或内容提交到仓库。

## 客户端边界

- [ ] 建立类型化 DTO 到领域模型的单一映射，移除调用方对原始响应字段的重复解释。
- [ ] 对非成功响应、畸形响应、分页中断和身份失效返回明确错误，不添加空结果 fallback。
- [ ] 保持目标服务使用的 REST、USN、冲突和附件语义。

## 真实服务验证

- [ ] 通过受保护环境变量注入测试凭据，并在日志初始化前启用敏感字段脱敏。
- [ ] 为本次运行生成唯一标记和资源账本，只操作运行中新建并登记的对象。
- [ ] 验证创建、读取、更新、多页 USN、冲突副本、附件上传下载和删除。
- [ ] 逆序清理账本对象；清理失败使验证失败并输出脱敏 ID，禁止扩大删除范围。

## 本地验证

- [ ] 运行针对 DTO、映射、分页、冲突、内容与附件的 JVM 单元测试。
- [ ] 运行 `.\gradlew.bat testDebugUnitTest`、`.\gradlew.bat lint` 和 `git diff --check`。
- [ ] 在 HTTPS 与平台任务完成后重跑目标服务端到端验证，确认实际客户端网络栈满足同一契约。

## 回滚点

- [ ] 固定夹具、领域映射和网络调用分开提交；任一步失败时恢复同一事实来源的全部对应文件。
- [ ] 真实服务清理失败时停止，不得用批量查询删除或账号重置掩盖遗留对象。
